# Day-to-day tasks related to software testing 

1. Requirement analysis for the new user stories and generate the test plan. 
2. Test design for the new user story and upload the test cases into Jira or Azure DevOps. 
3. Test execution for each and every test case and collecting the test results and create defect with in Jira /ADO
4. Identify the regression cases and then automate all the regression cases based on the existing Playwright framework. 
5. Maintaining the automation test cases and fixing the errors within the existing automation test scripts 
6. Enhance the existing framework by adding additional utilities whenever it's needed. 
7. Create the test cases based on the code available in the cloud repository, like GitHub, ADO, etc. 
8. Generating the test data for the test cases based on the requirement 
9. Creating the daily status report with the detailed test execution status, along with the defects identified and the status of the same 
10. Root cause analysis for the existing defects 
11. Remove the outdated test cases from the test suite
12. Creating detailed release notes
