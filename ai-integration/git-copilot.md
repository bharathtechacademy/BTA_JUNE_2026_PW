
## Copilots

Copilot is an AI-powered coding agent available as an extension in an IDE. 

Once the user is going to add that particular extension, it is going to connect our current IDE with the backend LLM. 

Example: In Visual Studio Code, if I am going to install the GitHub Copilot extension, automatically this GitHub Copilot extension is going to connect with all the available models in the market. 

## How will GitHub Copilot work, and what are all the different features of GitHub Copilot? 

GitHub Copilot is powered by backend LLMs. 

- It is going to understand your current file or your current project structure. 
- It will understand your existing framework patterns. 
- It will understand the comments written by the user to generate the code. 
- It will understand the libraries imported within the project and suggest the code according to the existing libraries.

## Different features of GitHub Copilot ?

1. Code Completion / Inline code suggestions 
Meaning, whenever we are going to write the code, automatically it is going to suggest the remaining part of the code to complete the program. 

2. Copilot chat (Ask Mode)
Copilot Ask mode in the Copilot chart is all about providing suggestions based on the user prompt without implementing or modifying any code in your codebase. 

3. Copilot chat (Agent Mode)
Copilot agent mode is all about providing the suggestions, at the same time updating all those suggested code directly inside your codebase and sending you all those changes for approval. 

4. Copilot chat (Plan mode. )
Copilot plan mode is all about creating an execution strategy before making the changes in the code. Meaning, Copilot is going to analyze the requirement, break it into multiple steps, then it is going to give you a strategy to complete. Once we approve the strategy, then it is going to start implementing the code in your personal project. 

5. Code testing => 
Copilot can generate the test cases for the existing code which we have written. It is going to verify, with different sets of data, how exactly the logic that we are going to create is working. It is also going to provide you with suggestions based on the output that we are going to receive. 

6. Debugging assistance => 
Copilot can analyze the errors and help identify possible root causes behind that particular error. 

7. Code explanation =>
It can explain the code, especially whenever we are exploring something new while developing the application or automating any application. 

8. Generating documentation 
Whenever we are going to write the code to develop the framework, we are going to create so many common methods. Now we can take help from the copilot to generate the detailed comments for each and every common method. 

9. Code review and pull request assistance 
Whenever one of our teammates is going to send the pull request after adding the new changes for our review, we can ask our copilot to review all those changes, and the copilot can suggest improvements. If the code is not working, it is also going to provide us with suggestions: how can we improve, how can we optimize, and how can we correct any errors that are found during the review process?
