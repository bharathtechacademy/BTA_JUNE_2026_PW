# What is Playwright? 
https://playwright.dev/  (Official Website)

Playwright is an end-to-end web automation framework created by Microsoft. By using Playwright, we can actually automate UI as well as API together. 

# What is the difference between Playwright and Selenium? 

Architecture => Selenium will use WebDriver protocol  , Whereas Playwright will use direct browser communication 

Synchronization Issues => In Selenium, we are going to use manual wait mechanisms to deal with the synchronization issue. Whereas Playwright is going to have inbuilt auto-wait. 

Language Support => Selenium supports most of the programming languages like Java, C#, Python, JavaScript, TypeScript, Ruby, etc. 
Whereas Playwright is going to support JavaScript, TypeScript, Java, Python,.NET (Core is TypeScript and JavaScript. )

Parallel execution => In Selenium, there is no parallel execution by default. Where as Playwright is going to come up with a default to parallel execution configuration 

API Testing Support => In Selenium, there are no default API testing-related libraries. Whereas Playwright is going to have a default API client to support API testing as well 

Video Recording => Selenium doesn't have any feature to record the video, but when it comes to Playwright, we are going to have a default video recording feature. 

TraceViewer => In Selenium, we don't have any Trace Viewer, but when it comes to Playwright, we are going to have the Trace Viewer feature to capture frame-by-frame screenshots along with the respective automation code. 

Code generator / MCP / CLI => Selenium doesn't have these features. But when it comes to Playwright, it will support:
- a code generator to generate the code
- MCP to automate the website
- CLI to help you during the automation process with limited tokens



## Default folder structure within the Playwright ?

1. node_modules => Node modules folder will have all the libraries downloaded on our local computer to work with Playwright and supporting libraries. 

2. tests => The folder where we are going to maintain all our Playwright test scripts with the format spec.ts 

3. .gitignore => The file that is going to ignore all unnecessary files and folders generated by Playwright when you are going to push the code 

4. Package.json => Package.json will contain all the JavaScript-related configurations and the additional libraries installed within the project folder. 

5. Package-lock.json => The additional supporting libraries downloaded when we are going to download the Playwright and other necessary utility-related libraries 

6. playwright.config.ts => All the Playwright configurations to control the test execution will be added under the Playwright configuration file.
